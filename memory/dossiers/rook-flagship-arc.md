## The filter order (for the next flagship hunt)

1. **Field Standard** (deepest): named system + sourced secret + victim; "everyone knows
   that" kills at the pitch. The vein: the DOJ complaint / court order / ISDA supplement /
   trustee record that names, proves, and victims in one document.
2. **International**: topic + data + one-line comprehension all work without country-specific
   prior knowledge (escape clause: US-anchored system OK if the mechanism is provably
   replicated abroad — say where).
3. **Experience/Knaller** (owner-side, not yet a formal gate): does the FRAME carry the
   mechanism? Cookie Roulette benchmark — banal topic, killer frame. A banal mechanism mapped
   1:1 into a banal interface inherits the banality.
4. Loglines first; development only on the owner's pick; the table's scoring measures craft,
   not the owner's blockbuster taste.
